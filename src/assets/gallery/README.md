# Villa Ledu — Gallery images

Drop any image here and it shows up automatically in the **Gallery** section
of the home page. No code changes needed.

- Supported formats: `.jpg` `.jpeg` `.png` `.webp` `.avif`
- Images display in **alphabetical order** — prefix with numbers to control it
  (`01-…`, `02-…`).
- The filename becomes the caption:
  `04-evening-terrace.jpg` → “Evening terrace”.
- Size hints for the masonry layout:
  - `…-tall.jpg` → taller, full-height tile
  - `…-wide.jpg` → wider tile
  - anything else → standard tile

Recommended: 1600–2400px on the long edge, optimised JPG/WebP.
